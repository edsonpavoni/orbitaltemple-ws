Orbital Temple / API reference / v1

Everything the temple
will tell a machine.

One service. The same orbit for everyone. The twelve sculptures are not a special case — they are the first client of this API, and anything they can ask for, you can ask for too.

Every route resolves its element set through the same resolver the sculptures use, so a mission TLE set once applies everywhere at once. An artist and a sculpture can never be looking at different orbits.

Base URL:

https://orbitaltemple.art/v1/orbit

Also reachable directly at https://us-central1-orbital-temple.cloudfunctions.net/orbit. Both work and return the same thing; prefer the short one.

Reads are public and need no key — it is the open sky, and a satellite carrying thousands of names. Writes are admin-only. CORS is open, so you can call these straight from a browser, a sketch, a Max patch or a microcontroller.

Public · no key

Where it is

Four routes. Everything below is live right now.
GET/position public

Where the satellite is this second, from wherever you are: look angles, the point on Earth it is directly above, how fast the range is changing, and the doppler shift your receiver would have to chase.

paramdefault
lat, lonSão Pauloyour observer position
freq_hz401500000downlink frequency the doppler is computed for
norad68377catalogue number, while a stand-in is flying
# Brooklyn, right now
curl "…/orbit/position?lat=40.6799&lon=-74.0028"

{
  "utc": "2026-09-22T19:10:59.747Z",
  "look":         { "az": 101.843, "el": -22.166, "range_km": 5948.25, "above_horizon": false },
  "ground_track": { "lat": 15.3774, "lon": -19.73629, "alt_km": 508.713 },
  "range_rate_km_s": -5.11257,     // negative = approaching
  "doppler_hz": 6847.06,
  "satellite": { "tle_source": "celestrak", "tle_epoch_utc": "2026-09-22T11:12:51.791Z" }
}
GET/passes public

When it comes over you next, how high it gets, and for how long. Rise and set azimuths tell you which way to face.

paramdefault
hours24how far ahead to look, up to 72
min_el10degrees above the horizon to count as a pass
curl "…/orbit/passes?lat=40.6799&lon=-74.0028&hours=24&min_el=10"

rise (UTC)             max el    dur   rise az   set az
2026-09-22T22:23:42      81.9   450s       164      350
2026-09-23T11:27:52      66.9   450s         6      202

Two passes in a day is normal for one satellite in a sun-synchronous orbit. It is overhead for seven and a half minutes at a time.

GET/tle public

The element set everything is currently following, where it came from, and how old it is. If you propagate your own orbit, start here — this is the same one the sculptures use.

curl "…/orbit/tle"

{
  "name": "SUPERVIEW NEO-2 05",
  "tle": [ "1 68377U 26062A   26265.46726611  …",
            "2 68377  97.4395 271.3917 0001571  …" ],
  "tle_source": "celestrak",          // "mission" | "celestrak" | "fallback"
  "tle_epoch_utc": "2026-09-22T11:12:51.791Z"
}

tle_source is the field to watch. mission means a specific element set has been pinned — which is what happens at launch, before the object has a catalogue number. fallback means the upstream fetch failed and a hardcoded orbit is being served: treat that as stale.

GET/schedule public

Twenty-four hours of azimuth and elevation at one-minute resolution. This is exactly what each sculpture downloads once a day and then plays against its own clock, with no network chatter in between. Fetch it once, interpolate locally, and your piece keeps working offline too.

paramdefault
hours24window length, up to 48
curl "…/orbit/schedule?lat=40.6799&lon=-74.0028&hours=24"

{
  "valid_from_utc": "2026-09-22T00:00:00.000Z",
  "samples_interval_sec": 60,
  "samples_count": 1440,
  "samples": [ { "t": 0, "az": 189.21, "el": -35.06 }, … ]
}

Elevation goes negative and that is not an error. For most of every orbit the satellite is below your horizon — on the other side of the Earth. The sculptures keep pointing at it through the planet.

The sculptures' own path, unchanged: https://orbital-temple.web.app/api/schedule

Byte-identical to /orbit/schedule. It stays exactly where it is — twelve sculptures fetch it every day.

Admin · key required

Pinning an orbit

How a satellite with no catalogue number gets followed anyway.

A newly launched object has no NORAD number until it is tracked and catalogued, which can take days. Until then no public source can describe it. The mission TLE is the override: paste a predicted element set once and every client — sculptures, artists, this API — follows it immediately.

GETPOSTDELETE /api/missionTleadmin key

Both lines are checksum-validated with the same rule the sculptures apply, on write and on read, and must carry the same catalogue number — pasting line 2 of a different object is the likeliest mistake and it is silent afterwards. An element set the boards would refuse cannot be stored here.

curl -X POST "…/missionTle" \
  -H "x-admin-key: ••••" -H "Content-Type: application/json" \
  -d '{"line1":"1 …","line2":"2 …","name":"ORBITAL TEMPLE"}'

# DELETE disables it and falls back to the catalogue.
# GET returns what is pinned, with its epoch.
Not built

What the satellite measures

Named here because it is promised, and because it is not ready.

There is no telemetry endpoint yet, and it would be dishonest to imply otherwise. Everything above is computed on the ground by propagating an orbit. None of it is measured by the spacecraft.

The satellite's own frame — battery, temperature, ambient light, gyroscope, accelerometer, magnetometer, storage, and the count of cosmic-ray bit flips it has corrected — comes down to ground stations. Nothing yet carries it from there to here. That link is the missing piece, and it is the one worth asking about.

When it exists it will appear as /v1/telemetry/latest and /v1/telemetry/history, in the same shape as everything above. Two fields are worth waiting for: LUX, which is sunrise roughly fifteen times a day, and SEU, a running count of the moments a charged particle changed the satellite's mind and the satellite changed it back.

Notes

Small print

Caching, errors, and what to expect.
  • /position is cached 1 s, /passes and /tle 5 min, /schedule 1 h. Pass a changing query parameter to bypass the cache.
  • Errors are JSON with an error field. An unknown route returns 404 and lists the routes that do exist.
  • Every response carries schema, so you can tell if a shape changes under you.
  • Angles are degrees, distances kilometres, times ISO-8601 UTC. Azimuth is compass degrees from north; elevation is degrees above the horizon, and negative below it.
  • While a stand-in satellite is flying, norad lets you point any route at a different catalogued object.
